3-Layer Hybrid Retrieval
1
Memory Graph
Named entity → node → edges → memory IDs. Instant. "Marcus" → 3 IDs in one hop.
2
DynamoDB Keyword
Fetch all, score by field overlap (who / what / when / tags). Always fresh — catches memories added seconds ago.
3
Bedrock KB Semantic
Vector similarity via Knowledge Base. Best-effort fallback. Failures silently swallowed — layers 1+2 cover freshness.
Guardrails
PII Scrubbing
Phone · email · SSN · card · passport ID stripped from all memory fields before DynamoDB + S3 write.
Rate Limiting
20 req/min per IP on /api/converse. Sliding window. 429 + Retry-After on excess.
